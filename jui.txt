ЧТО ДЕЛАЕТ
- Слушает входящий серверный чат, который реально получает именно ваш игровой клиент (samp.events.onServerMessage).
- Объединяет сообщения за ~3 секунды и отправляет их в личный чат Telegram-бота через HTTPS.
- Сохраняет порядок, время, переводит текст из CP1251 в UTF-8 и убирает цветовые коды вида {FFFFFF}.
- При временных сбоях Telegram повторяет отправку из очереди, обрабатывает HTTP 429.
- Не изменяет сетевые пакеты, не мешает ConnectTools v3.7, автологину, реконнекту и выбору спавна.

УСТАНОВКА
1. Распакуйте все ТРИ файла из ZIP в одну папку с Lua-скриптами NeoMLoader:
   - NeoTelegramChat.lua
   - NeoTelegramChat_config.json
   - NeoTelegramChat_CA.pem
2. В Telegram создайте собственного бота у @BotFather. Получите BOT TOKEN.
3. Напишите этому боту /start в ЛИЧНОМ чате. Бот не может первым начать диалог.
4. Узнайте свой Telegram числовой ID (например, у @userinfobot).
   Для личного диалога после /start этот ID используется как admin_chat_id.
5. Откройте NeoTelegramChat_config.json в текстовом редакторе, замените:
     PUT_BOT_TOKEN_HERE   -> токен BotFather
     PUT_YOUR_CHAT_ID_HERE -> свой числовой Telegram ID
   Сохраняйте кавычки и остальной JSON.
6. Загрузите NeoTelegramChat.lua через менеджер Lua, либо перезапустите игру.
7. В игре введите /tgtest. Через несколько секунд в личный чат бота должно прийти тестовое сообщение.
8. Введите /tgstat: recv — полученные строки, sent — переданные, queue — очередь,
   dropped — строки, отброшенные после переполнения очереди.

КОМАНДЫ
  /tgtest    — послать тестовое сообщение через ту же очередь
  /tgstat    — состояние, счётчики и ошибки
  /tgpause   — временно остановить сбор сообщений
  /tgresume  — возобновить сбор

НАСТРОЙКИ
- enabled: true — включить трансляцию.
- include_outgoing_chat: false — не отправлять исходящий чат дополнительно.
  При true добавляются ваши обычные сообщения, но некоторые продублируются,
  поскольку сервер показывает их и во входящем чате. Slash-команды исключены.
- batch_seconds: 3 — интервал группировки сообщений.
- max_batch_lines: 25 — максимум строк в одной посылке.
- max_queue_lines: 1500 — ограничитель памяти/очереди. При превышении старые строки
  заменяются новыми, а счётчик dropped показывает количество потерянных строк.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Это не доступ к общему чату сервера изнутри админ-панели. Видно только то, что
  реально отправляется вашему клиенту через серверный чат. История до запуска
  скрипта, невидимые сообщения других игроков, диалоги/текстдравы не собираются.
- Пока игра полностью закрыта, Lua не работает и ничего не записывает.
- Очередь хранится только в памяти. После полного закрытия клиента она теряется.
- В периоды огромного потока или длительного отсутствия интернета часть строк
  может быть вытеснена из очереди; абсолютную 100% доставку обещать нельзя.
- Бот должен быть личным. Не пересылайте его токен третьим лицам и не публикуйте
  конфиг или логи с данными аккаунта. При утечке токена смените его через BotFather.
- Любое содержимое видимого игрового чата, включая личные сообщения/уведомления,
  попадёт в Telegram. Учитывайте приватность своих собеседников.
- Сетевые запросы выполняются через Copas + LuaSec с проверкой сертификата по
  приложенному списку CA. В отдельных Android/NeoMLoader сборках HTTPS может
  не пройти проверку; в этом случае пришлите лог БЕЗ bot_token и файла конфигурации.
- Мы проверили синтаксис и эмуляцию отправки/очереди. На настоящем телефоне этот
  скрипт ещё НЕ протестирован. Если /tgtest не дошёл, отправьте neomloader.log,
  предварительно убедившись, что в нём нет паролей/токенов.
